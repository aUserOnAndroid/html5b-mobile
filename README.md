# HTML5b Mobile Port

An Mobile port of Cary Huang's flash game [HTMl5B](https://coppersalts.github.io/HTML5b/) using only pureJS and HTML5. Everything relating to the gameplay has been implemented and the level creator has had all its major functionalities implemented. Once all the minor fixes are implemented; I will move on to adding the 5b level sharing platform called "Explore".
